# 0_specs — what this repo is

Specifications for `tools`: what it does, how it is designed, who it is for.

Convention across every repo under cloud:

- `eng-specs/`   architecture, design, test plans
- `prod-specs/`  product requirements
- `user-specs/`  user-facing documentation

Sibling headers: `0_tasks/` (what is being done) and `1_configs/` (how the
repo runs).
